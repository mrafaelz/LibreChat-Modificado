# Selección de mercados AREX

Usa `arex-fundamentos` junto con esta skill cuando el usuario deba elegir o priorizar países destino.

## Datos insuficientes

Si faltan datos que puedan alterar la selección, pide al usuario los datos materiales con preguntas concretas y breves antes de emitir un ranking o recomendación firme. No inventes producto, partida, capacidades, objetivos, cifras, fuentes ni restricciones. Limita las suposiciones a las estrictamente necesarias para una orientación inicial, decláralas de forma visible y explica qué dato las confirmaría o podría cambiar el resultado.

## Construir el análisis

Define producto y partida HS6 si están disponibles, objetivo (volumen, margen/premium, rapidez o prudencia), capacidad y restricciones reales de la empresa. Si la clasificación o el producto es ambiguo, explica el efecto sobre el resultado antes de escoger una partida.

Para elaborar un ranking, consulta datos actuales y específicos del producto cuando estén disponibles. Si no puedes acceder a esos datos, dilo expresamente y no presentes un ranking definitivo, ni asignaciones numéricas que aparenten precisión. Ofrece, como mucho, una preselección o hipótesis condicionada, identifica qué evidencia falta y solicita la partida HS6 o los datos decisivos que no estén disponibles. Si la partida HS6 no puede determinarse con seguridad, pide la descripción técnica, composición, uso y formato comercial necesarios para clasificarla antes de comparar mercados.

Evalúa el universo de mercados cubierto por los datos, salvo que el usuario imponga una zona o restricción logística. Puntúa las dimensiones simultáneamente; no uses filtros implícitos que eliminen oportunidades antes de comparar sus compensaciones:

- Demanda: tamaño y evolución de importaciones, cuota de España, concentración de proveedores y brecha entre importación total y ventas españolas.
- Acceso: arancel efectivo para origen España, requisitos técnicos y sanitarios, barreras notificadas y factibilidad logística.
- Viabilidad: riesgo país, estabilidad de pago/divisa, distancia y ajuste con recursos, certificaciones y experiencia de la empresa.

Justifica los pesos con el objetivo y perfil. Un ratio aduanero valor/peso puede servir como señal estadística de posicionamiento, nunca como precio comercial concluyente.

## Entrega

Muestra los mercados con mejor resultado en una tabla de criterios, pesos, evidencia y puntuación. Explica cuántos se evaluaron, por qué el grupo final tiene ese tamaño y qué candidatos quedaron cerca. Para decisiones importantes, compara un escenario de crecimiento con uno conservador y señala las variables que cambiarían el ranking.

Cuando falten datos actuales o datos críticos del producto, sustituye la tabla de puntuación por una tabla breve de hipótesis, evidencia disponible, lagunas y acción de validación. Distingue de forma visible entre un ranking respaldado por datos y una orientación preliminar.

Termina con uno o dos mercados priorizados, condiciones para avanzar y el paso siguiente —normalmente canal, validación de precio o requisitos de acceso—. Expón límites de cobertura, fecha y calidad de las fuentes.
